# Triage Labels

Skill menggunakan lima peran triage kanonik berikut. File ini memetakan peran tersebut ke nama label yang digunakan di GitHub Issues repo ini.

| Label di mattpocock/skills | Label di tracker kita | Arti                                          |
| -------------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`        | Maintainer perlu mengevaluasi issue ini       |
| `needs-info`               | `needs-info`          | Menunggu informasi tambahan dari pelapor      |
| `ready-for-agent`          | `ready-for-agent`     | Spesifikasi lengkap, siap dikerjakan agent    |
| `ready-for-human`          | `ready-for-human`     | Membutuhkan implementasi manusia              |
| `wontfix`                  | `wontfix`             | Tidak akan ditindaklanjuti                    |

Saat skill menyebut sebuah peran (misalnya "apply the AFK-ready triage label"), gunakan nama label yang sesuai dari tabel ini.

Edit kolom kanan jika ingin menyesuaikan dengan label yang ada di repo.
