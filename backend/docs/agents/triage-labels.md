# Triage Labels

Skill engineering menggunakan lima peran triage kanonis. File ini memetakan peran tersebut ke string label yang digunakan di issue tracker repo ini.

| Label di mattpocock/skills | Label di tracker kita | Arti                                                  |
| -------------------------- | --------------------- | ----------------------------------------------------- |
| `needs-triage`             | `needs-triage`        | Maintainer perlu mengevaluasi issue ini               |
| `needs-info`               | `needs-info`          | Menunggu informasi tambahan dari pelapor              |
| `ready-for-agent`          | `ready-for-agent`     | Spesifikasi lengkap, siap dikerjakan oleh agen AFK    |
| `ready-for-human`          | `ready-for-human`     | Memerlukan implementasi oleh manusia                  |
| `wontfix`                  | `wontfix`             | Tidak akan ditindaklanjuti                            |

Saat skill menyebut suatu peran (mis. "apply the AFK-ready triage label"), gunakan string label yang sesuai dari tabel ini.

Ubah kolom tengah agar sesuai dengan kosakata label yang Anda gunakan.
